# Inventory Sorter Port

A Minecraft mod for simple inventory sorting, now with a **sort button** for easier access.  
Forked from [inventorysorter](https://github.com/qyurila/inventorysorter) and enhanced with additional features.

**Supports Forge 1.20.1 only.**

## Features

- **Inventory sorting** via middle‑click or custom hotkey  
- **Optional sort button** on inventory GUIs (can be toggled in config)  
- Configurable sort order (Quark style, Creative Tab, Item ID, etc.)  
- **Failsafe** to prevent item loss (especially with Curios, Sophisticated Backpacks, Dank Storage)  
- Option to **keep hotbar unsorted** (enabled by default)  

## Links

- [GitHub](https://github.com/qyurila/Inventory-Sorter-Port)  

## Installation

This mod requires installation on **both client and server** to function.  
Delete any other inventory sorting mods before adding this one to avoid conflicts.

## Configuration

Sort order and button visibility can be changed in the config file (may require game restart).
